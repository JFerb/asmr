# Setup and Installation

This file is the main entry point for the ASMR tutorial setup instructions. It separates workstation setup from software installation.

## Workstation setup

- `windows.md` — Windows host setup using WSL with Ubuntu 24.04.
- `vm.md` — VirtualBox guest setup using Ubuntu 24.04.
- `jupyterhub.md` — University JupyterHub access and usage.

## Software setup

- `python.md` — local Python / Conda environment setup.
- `ros-gz.md` — ROS 2 Jazzy and Gazebo Harmonic installation resources.

## Prerequisites

- Ubuntu 24.04 LTS 
- Python 3.11 or later
- ROS2 Jazzy with Gazebo Harmonic

## Next step

Choose the path that matches your situation:

| Your setup | Follow |
|---|---|
| Windows PC | `windows.md` → then `python.md` |
| Mac or Linux (no VM) | `python.md` directly |
| University computer lab / no admin rights | `jupyterhub.md` |
| Want a clean Ubuntu VM | `vm.md` → then `python.md` |
